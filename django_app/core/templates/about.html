How it works

Code:

  • Python, Django Webframework 4.2.4
  • Terraform for infrastructure

Infrastructure:

  • Django runs on AWS Fargate, SQS queue used for messages, Lambda to process SQS. Postgres as database.
  • Azure OpenAI GPT-4
  • To-do list items and categories are created with OpenAI function calling.
